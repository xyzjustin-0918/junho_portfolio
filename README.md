# 배움의 기록

서울대학교 첨단융합학부에서 만난 배움을 카드뉴스로 모은 포트폴리오입니다.

## 분류

작업은 세 가지 큰 주제만 사용해 JavaScript `Map`으로 묶었습니다.

- 교외교육: 3개 작업
- 비교과: 7개 작업
- 전공 톺아보기: 4개 시리즈

총 14개 작업, 62장입니다. 카드뉴스는 표지에서 시작해 원본 Artboard 번호 순서로 볼 수 있습니다.

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages에 배포하면 됩니다. 정적 HTML, CSS, JavaScript만 사용합니다.
