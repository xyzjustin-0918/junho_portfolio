# 배움의 기록

서울대학교 첨단융합학부에서 만난 배움을 카드뉴스로 모은 포트폴리오입니다.

## 분류

작업물과 카드 페이지는 배열로 관리합니다. 선택한 범주에 맞는 작업물을 배열에서 찾고, 최신순과 제목순 정렬에는 직접 구현한 병합 정렬을 사용합니다. 최신순은 행사 날짜를 기준으로 하며 날짜가 없는 전공 시리즈는 회차를 기준으로 합니다. 분류는 O(n), 병합 정렬은 O(n log n)입니다.

- 교외교육: 3개 작업
- 비교과: 7개 작업
- 전공 톺아보기: 4개 시리즈

총 14개 작업, 62장입니다. 카드뉴스는 표지에서 시작해 원본 Artboard 번호 순서로 볼 수 있습니다.

## 실행

`index.html`을 브라우저에서 열거나 GitHub Pages에 배포하면 됩니다. 정적 HTML, CSS, JavaScript만 사용합니다.
